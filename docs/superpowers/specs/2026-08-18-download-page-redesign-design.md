# 下载页 UI 重设计

**日期：** 2026-08-18
**状态：** 已确认（方案 A）

## 目标

在不改变产品信息的前提下，将下载页从当前平铺结构重设计为「现代 SaaS 产品站」风格，提升视觉吸引力，保持全站简洁、非科幻的既有设计语言。核心交互（复制校验值、折叠更新日志）保留。

## 约束

- 保持非科幻、浅色编辑化风格（Slate 中性色 + 品牌蓝 `#2f6fdd`），沿用现有全局 CSS 变量与设计系统 MASTER。
- 保留全部现有内容：版本信息、平台支持、更新日志、系统要求、SHA-256 校验值、三步引导。
- 下载按钮保持「诚实待开放」状态（安装包未公开托管），不虚构可用按钮。
- 保持无障碍：44px 触控目标、可见焦点、`prefers-reduced-motion`、移动端单列堆叠。
- 现有测试断言必须继续通过：`tests/rendered-html.test.mjs` 要求下载路由包含 `Stellara Work-Setup-0.9.0.exe`、`111.8 MiB`、`下载通道准备中`、SHA-256 值。

## 页面结构

### 1. 首屏 Hero（左右分栏）
- **背景**：柔和渐变 `linear-gradient(180deg, #ffffff, #eef4ff)`，底部细边框。
- **左栏**
  - eyebrow：状态点 + `v0.9 内测版`
  - 大标题：`下载 Stellara Work`
  - 副文案（保留现有）
  - 下载按钮区：大号禁用主按钮「下载通道准备中」+ 说明文字 `安装包已构建 · 111.8 MiB · x64 · 2026-07-30`
  - 反馈条：绿色 `✓ 已通过本地构建验证，公开文件托管通道正在准备`
  - 版本徽章行（chips）：`Windows x64 可下载`、`NSIS 安装向导`、`版本 0.9.0`
- **右栏**：产品演示窗口（新组件 `DownloadDemo`）
  - 模拟 Stellara Work「首次引导」界面：窗口控制条 + `Stellara Work · 首次引导` 标题 + 版本号
  - 左侧深炭引导步骤（选择模型 → 选择目录 → 连接测试），第 1 步高亮
  - 右侧内容区：模型/工作目录信息条、Agent 消息、审批条（拒绝/允许这一次）、连接测试通过提示
  - 顶部叠加一层极淡蓝色辉光 `radial-gradient`，增强层次但不科幻

### 2. 平台支持区
- 3 张卡片：Windows（可用，蓝色描边 + 蓝底图标 + 绿色「可下载」徽章）、macOS / Linux（灰态「尚未提供」）
- 文案保留现有

### 3. 版本信息区
- 左：更新日志卡片（面板标题 + 日期 + 5 条勾选列表，保留折叠交互）
- 右：安装信息侧卡（系统 / 包体积 / 文件名，分隔行排版）

### 4. 校验值区
- 单张横向卡片：图标 + 说明 + SHA-256 等宽哈希 + 复制按钮（保留已复制反馈）

### 5. 快速开始区
- 深炭底色圆角区，3 步卡片（选择模型 → 选择目录 → 描述任务）+ 「阅读快速开始」链接

### 6. 页脚
- 沿用现有 `SiteFooter`，无改动

## 视觉规范

- 颜色全部引用现有 `globals.css` 变量（`--blue`、`--blue-soft`、`--green`、`--charcoal`、`--line` 等），新渐变仅在 hero 与演示窗内使用。
- 圆角：`--radius-lg`（14–16px）卡片、`--radius-md`（8–10px）按钮/输入。
- 阴影：演示窗口用 `--shadow-lg`，卡片用轻量 `0 10px 24px rgba(20,23,29,.05)` 级别。
- 演示窗口字号按比例缩小（8–11px），沿用首页 `HomeDemo` 的微型界面画法。
- 移动端（≤860px）：hero 改单列，演示窗口置于标题下方；平台/步骤卡片单列堆叠；`≤640px` 进一步收缩字号与间距。

## 非目标

- 不新增页面或路由。
- 不引入真实安装包下载链接。
- 不改变首页、文档页样式。
- 不改动现有设计系统 token 的既有取值。

3. `npm run build` 成功；必要时执行 GitHub Pages 静态导出检查三路由产物。
4. 手动核对浏览器：桌面/移动端布局、复制反馈、折叠更新日志、reduced-motion。
